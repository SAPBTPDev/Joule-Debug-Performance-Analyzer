Joule Debug Performance Analyzer

Load one or more Joule debug JSON exports (Joule panel → ⋯ → Download debug info). Everything is parsed in your browser; nothing is uploaded.

How the times are calculated

A turn starts when the user's message reaches Joule and ends with Joule's last reply to it. Time between Joule's reply and the next user message is idle (user reading/typing) and is excluded from processing time.

  • Joule – scenario selection: user message → SCENARIO_SELECTED (Joule understands the input and picks the skill).
  • Joule – parameter filling: SCENARIO_SELECTED → SCENARIO_EXECUTED_WITH_PARAMETERS.
  • Custom – API calls: for each I_API_EXECUTION, the gap since the previous log event. Includes destination / Cloud Connector / S/4 time.
  • Custom – skill logic: the rest of the turn between the first and last log event (conditions, set variables, messages, sub-skill hand-offs).
  • Joule – rendering: last log event → Joule's reply timestamp.

Turns with no logs (for example Joule answering on its own) are counted entirely as Joule time. A user message without a server timestamp (isSending) never reached Joule and is flagged.
